       The Five AI Agents
      
        
      
          
      
            
      🔍 Recipe Retrieval Agent
      
            
      Searches uploaded recipe documents and the built-in knowledge base using TF-IDF / cosine similarity (RAG retrieval step).
      
          
      
          
      
            
      👨‍🍳 Recipe Generation Agent
      
            
      Calls IBM Granite via watsonx.ai to generate a personalized recipe, using the retrieved context as grounding.
      
          
      
          
      
            
      🥗 Recipe Adaptation Agent
      
            
      Modifies a recipe's ingredients and instructions to match a target dietary preference (Vegan, Keto, Gluten-Free, etc.).
      
          
      
          
      
            
      🥑 Nutrition Analysis Agent
      
            
      Estimates per-serving nutritional values (calories, protein, carbs, fat, fiber) for the generated recipe.
      
          
      
          
      
            
      🛒 Shopping List Agent
      
            
      Takes recipe ingredients, removes items the user already has, and categorises the rest into a structured shopping list.
      
          
      
        
      
      
      
    
      
    
      
      
      
        
       RAG Architecture
      
        
      
          
      
            USER QUERY
      
               ↓
      
            DOCUMENT SEARCH (TF-IDF)
      
               ↓
      
            TEXT CHUNKING & RETRIEVAL
      
               ↓
      
            RELEVANT CONTEXT
      
               ↓
      
            IBM GRANITE PROMPT
      
               ↓
      
            GENERATED RECIPE
      
               ↓
      
            FRONTEND DISPLAY
          
      
          
      
          
      
            When IBM credentials are configured, real IBM Granite AI is used for generation. When credentials are absent, the system uses built-in sample data and intelligent fallback responses to demonstrate the complete workflow.
          
      
        
      
      
      
    
      
  
      

  
      
    
       About This Project
      
    
      
      
      ChefGPT AI is a college project demonstrating Agentic AI and Multi-Agent Collaboration for intelligent recipe generation. It uses Retrieval-Augmented Generation (RAG) to ground AI responses in real recipe documents uploaded by the user.
      
      
      The Master Orchestrator coordinates five specialised agents — retrieval, generation, adaptation, nutrition, and shopping — each handling a distinct responsibility. IBM watsonx.ai and IBM Granite models provide the AI reasoning layer.
      
      
      To enable IBM Granite AI: add your WATSONX_API_KEY and WATSONX_PROJECT_ID to the .env file, then restart the Flask server.
